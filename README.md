# Convolution-Reverberation-Python
A python convolution algorithm to apply reverberation to a given file via an impulse response.

## Prerequisites
The program requires the following modules to be installed in order to run:
  1. numpy
  2. wave
  3. struct
  4. scipy
  5. pathlib

## Usage
  1. When prompted, copy and paste the file directory for the sample file of your choosing.
  2. When prompted, copy and paste the file directory for the impulse response included within the program.
  3. Input your desired parameters for the sample rate and wet/dry gain. If you are unsure what to do, leave blank for the defaults.
  4. Wait until the program outputs the file in the same directory where the main_algorithm.py file was placed as "output.wav". **Make sure there is not a file named "output.wav" in the directory before running the program.**
